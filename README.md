## Hosting i własna domena

GitHub Pages publikuje katalog główny gałęzi main. Strony nie wymagają JavaScript, logowania, zewnętrznych fontów ani systemu budowania. Nie dodają analityki.

Weryfikacja domeny Google OAuth wymaga zgodnie z bieżącą instrukcją Google usługi Domain w Search Console i rekordu DNS TXT dodanego przez właściciela projektu Google Cloud. Sam prefiks URL github.io nie zastępuje tego wymagania. Własną domenę lub subdomenę można podłączyć w Settings → Pages → Custom domain tego repozytorium; nie zmieniaj w tym celu domeny repozytorium altstore-source. Po podłączeniu domeny uaktualnij adresy canonical, og:url, og:image, robots.txt, sitemap.xml i adresy w tym pliku. DNS nie jest częścią tego repozytorium.

Materiały marki odpowiadają ikonie wersji 0.9.2 aplikacji. Na ekranie zgody Google używaj pełnej nazwy Apka do Faktur, tego samego logo i publicznych odnośników do strony oraz osobnej polityki prywatności. Aktualne zasady Google: https://support.google.com/cloud/answer/13804266?hl=en oraz https://support.google.com/cloud/answer/15549049?hl=en .
